#TAREFA 003.5

Refaça a dedução da cinemática inversa vista em aula de forma extremamente simples, como se estivesse explicando para uma criança de 5 anos.

Instruções:

-Uso de figuras: Utilize desenhos e diagramas ilustrativos para tornar a explicação visual e intuitiva.

-Clareza e descrição: Seja o mais didático possível para simplificar conceitos complexos.

-Avaliação por pares: Seu trabalho será corrigido por um colega. Se a explicação não ficar perfeitamente clara para quem estiver avaliando, a nota será zero.
